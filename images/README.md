# 🎨 Canva 그림 넣는 방법

이 폴더에 아래 **파일 이름 그대로** PNG 그림을 넣으면 웹앱 카드에 자동으로 표시됩니다.
그림이 없으면 이모지가 대신 나옵니다. (권장 크기 **800 × 520 px**, 가로형)

Canva → **Magic Media(텍스트로 이미지 만들기)** 에 아래 프롬프트를 넣어 만들고,
**다운로드 → PNG** 로 저장한 뒤 이름을 바꿔 이 폴더에 넣으세요.
스타일은 모두 같게 맞추면 보기 좋아요 (예: *Illustration / 3D cartoon*).
